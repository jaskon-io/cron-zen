# 与 cron.ren 对照

<p class="cz-lead">
交互与输出以 cron.ren / Quartz 习惯为基准，便于迁入自有系统。下表列出已对齐项与已知差异。
</p>

## 已对齐

| 能力 | 行为 |
| --- | --- |
| 年「不指定」 | 输出 **6 段**，不强制尾部 `*` |
| 日 / 周互斥 | 一侧具体值时，另一侧自动为 `?` |
| 周数字 / 英文 | `1~7`（1=周日）或 `SUN…SAT` |
| `6L` 等数字写法 | 不误判成 abbr（避免写成 `FRIL`） |
| 倒序区间 | 如周「周六→周二」保留 `7-3`；近 N 次按环形回绕估算（自 0.1.2） |
| 日 `LW` / `L` / `nW` | 解析 + UI + 近 N 次（自 0.1.2） |
| 周 `nL` / `n#m` / 裸 `L` | 解析 + UI；近 N 次可估（自 0.1.3） |
| 月「指定」标签 | 格子显示「1月」…「12月」（自 0.1.2） |
| 自然语言（周） | 区间/列表输出「周一至周五」等（自 0.1.1） |
| 空值编辑 | `v-model` 为空不注入默认 Cron |
| `%` 转义 | 降低下游调度解析失败概率 |

## 已知差异

| 项 | cron-zen |
| --- | --- |
| 经典表 `* * MON-FRI` | 加载后日段规范为 `?`（Quartz 合法态） |
| 月名 `JAN` 输入 | 仍作非标准降级保留；UI 已用中文月标签 |

## 为何仍选 cron-zen

| 诉求 | cron.ren 站点 | cron-zen |
| --- | --- | --- |
| 嵌进业务表单 | 弱 | 强 |
| 不绑 UI 库 | — | 支持 |
| 单测 / 版本化 | — | 支持 |
| 主题 / 二次开发 | — | MIT + CSS 变量 |

对照问题请附表达式提交 [Issue](https://github.com/jaskon-io/cron-zen/issues)。
