# 与 cron.ren 的差异

`cron-zen` 的交互与输出以 [cron.ren](https://www.cron.ren/index.html) / Quartz 习惯为基准，方便从该站点迁到自有系统。下面列出**已对齐**与**已知差异**，便于评估。

## 已对齐（主路径）

| 能力 | 说明 |
| --- | --- |
| 年「不指定」 | 输出 **6 段**（如 `* * * * * ?`），不强制尾部 `*` |
| 日 / 周互斥 | 一侧具体值时，另一侧自动变为 `?`，UI 有提示 |
| 周数字 / 英文 | `1~7`（1=周日）或 `SUN…SAT`；列表默认从周一 |
| `6L` 等数字写法 | 不会误判成 abbr 改写成 `FRIL` |
| 倒序区间 | 如周「周六→周二」保留 `7-3`（与 cron.ren 一致） |
| 空值编辑 | `v-model` 为空不注入默认 Cron，避免污染表单 |
| `%` 转义 | 生成侧处理，降低下游调度解析失败概率 |

## 已知差异 / 限制

| 项 | cron-zen 行为 |
| --- | --- |
| 经典表 `* * MON-FRI` | 加载后日段会规范为 `?`（Quartz 合法态） |
| 自然语言预览 | 周区间可能显示为「周 2-6」而非「周一至周五」 |
| `LW` / 月名 `JAN` | 可解析保留，UI 暂无独立选项 |
| 近 N 次 | `L` / `W` / `#` / 倒序区间等复杂写法可能无法估算（列表为空） |

## 为什么还要用 cron-zen

- **引擎可嵌入**：`@cron-zen/core` + 可选 Vue 外壳，不是外链页面。
- **不绑 UI 库**：默认 `CronZen` / `useCronZen`；弹窗用你现有的 Ant / Naive / 自研壳（见 [任意 UI 集成](./any-ui)）。
- **可测试**：core 有完整单测，行为可回归。
- **可主题化**：CSS 变量；Element 只是可选 Picker 壳。
- **可演进**：开源 MIT，差异项可按 issue 补齐。

发现问题欢迎在 [GitHub Issues](https://github.com/jaskon-io/cron-zen/issues) 反馈，并附上 cron.ren 对照表达式。
